# LLM Tuner 0.6.1

Release candidate for v0.6.1.

## Highlights

- **Privileged Ollama Storage Configuration on Linux**:
  - Interactive `sudo` elevation support in both the Web/Desktop UI modal dialog and the CLI.
  - Automatic systemd drop-in generation at `/etc/systemd/system/ollama.service.d/models.conf` with `Environment="OLLAMA_MODELS=<path>"`.
  - Automatic ownership adjustment (`chown -R ollama:ollama <path>`), daemon-reload, and background service restart with polling verification.
  - Clear guidance on filesystem traversal permissions (`chmod o+x` / ACLs) when configuring custom model paths under user `/home/` directories.
- **In-Place Non-Destructive Dashboard Polling**:
  - Background telemetry and active model polling every 5 seconds now updates DOM elements in-place.
  - Active search filter inputs, text inputs, and open modal dialogs are fully preserved during polling cycles.
- **Test Suite Hardening**:
  - Ollama `modelsDir` detection tests now account for custom systemd overrides and verify directory accessibility dynamically.
  - Automated test suite expanded to 542 passing tests across 28 suites.
- **Synchronized Documentation**:
  - Updated `README.md` (English) and `README.es.md` (neutral Spanish) with exact heading and feature parity.

## Compatibility

- Node.js 24 or later required.
- Linux, macOS, and Windows supported.
