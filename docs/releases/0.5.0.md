# LLM Tuner 0.5.0

Local release candidate; not yet published by this preparation task.

## Highlights

- Run a headless daemon on a dedicated GPU computer and connect clients through configured remote servers.
- Add, test, and select servers in Settings using bearer-token authentication.
- Route Web/Desktop requests through the active server and resolve remote engine hosts for MCP setup.
- Enable optional server startup after user login from CLI or Desktop Settings.
- Reveal saved connection tokens through explicit local actions, with a Desktop copy action.
- Discover a connectable LAN address instead of presenting the wildcard listen address, and support browser CORS preflight requests.

## Compatibility and Scope

- Node.js 22 or later remains required.
- This release preparation changes package versions only; dependencies and the release workflow are unchanged.
- Login startup is per-user and opt-in, not a machine-wide boot service. Real operating-system login startup needs platform smoke testing; mocked tests alone do not prove it.
- This summary covers application changes in local `main` since `v0.4.4`. Repository tooling and planning-only changes are not application features.

## Verification and Publication

Fresh preparation checks and their observed results are tracked in [the release story](../userstories/release-0-5-0/README.md). Historical test results in older feature documents are not fresh verification of this candidate.

Publication is a separate action: the existing workflow tests pushes to `release`, publishes to npm, then creates the version tag and GitHub release. This preparation does not trigger that workflow or publish artifacts.
